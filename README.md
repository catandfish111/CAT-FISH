# 写给你的一封信 💌

一个可以用**微信直接打开**的情侣小站：打开是一枚会呼吸的信封，轻触之后信封打开、信纸展开，
里面用**打字机**一个字一个字打出你的心里话（光标是一颗跳动的小爱心），中间自动播放你放的视频，
最后是落款和心跳爱心。

陪着你的是三只手绘的卡通形象：**小猫**、**小鱼**和**装爱心的小罐子** —— 它们会在信封旁偷看、
在信纸角落轮流出场、还会吐泡泡和留下爪印；**点它们一下**，会撒出一把爱心或泡泡。
背景飘着爱心、泡泡、猫爪印和小星星，结尾会下一场爱心雨。

```
happy/
├── index.html      ← 入口（微信里打开的这个文件）
├── styles.css      ← 外观（配色、形象大小、动效都在这里）
├── config.js       ← ★ 你只需要改这个文件：文字、视频、形象、开关
├── app.js          ← 动画与流程逻辑 + 小猫/小鱼的 SVG 造型
├── assets/         ← ★ 把视频放进这里
└── tests/          ← 自检脚本（不影响站点，可删）
```

## 1. 先看效果（在你电脑上）

用命令行进到本文件夹，起一个本地服务器（**不能用 `file://` 直接打开**，浏览器会拦掉视频）：

```powershell
# 任选一种
python -m http.server 8080
npx serve -l 8080
```

然后浏览器打开 <http://127.0.0.1:8080> 。
按 `F12` 打开开发者工具，点左上角的手机图标切到手机尺寸（比如 iPhone 12），看到的就是微信里的效果。

## 2. 换成你自己的内容

打开 `config.js`，所有内容都在里面，改完保存、刷新页面就行：

```js
window.LOVE_CONFIG = {
  cover: {
    intro: '写给你的一封信',      // 信封上方的小字
    hint: '轻触这里，打开信封',    // 信封下方的呼吸提示
    miniNote: '只给你看'          // 信封里露出的那张小纸条
  },

  /* 卡通形象：关掉哪个就把哪个改成 false；enabled:false 是全部关掉
     seal 是信封上那枚火印的图案：'fish' 小鱼 / 'heart' 爱心 */
  mascots: {
    enabled: true,
    cat: true, fish: true, jar: true,
    seal: 'fish'
  },

  stages: [                      // 一幕一幕往下演（默认写了 8 幕）
    {
      name: '启封',               // 左上角显示的小标签
      title: '写给猫猫和鱼鱼',      // 信纸顶部的标题（打字机会把它打出来）
      mascot: 'jar',             // 这一幕陪着你的形象：cat / fish / jar；不写就三只轮流
      open: [                    // 打字机逐字打出的段落，一个字符串就是一段
        '展信佳。',
        '这封信我写了好久……'
      ]
    },
    {
      name: '第一幕',
      title: '偷偷留下一段',
      mascot: 'fish',
      open: ['我偷偷录了一小段。', '画面有点抖……'],
      video: 'assets/video1.mp4', // ← 你的视频；留空 '' 就自动跳过这一幕的视频
      poster: '',                 // ← 可选：视频封面图
      caption: '那天偷偷录了一小段。', // ← 视频下面那行小字
      close: ['其实那天我紧张得手心全是汗。'] // ← 视频播完之后再打出来的话
    }
    // …想加就照抄一个 { } 粘上去，想删就整段删掉
  ],

  ending: {
    sign: '永远站在你这边的人\n留于某个想你的深夜', // \n = 换行
    replay: '轻触重新看一遍'
  },

  video: {
    mode: 'inline',   // inline = 在信纸里播放（推荐）；cine = 全屏播放
    muted: true,      // 首次自动静音（微信要求），视频角上的按钮可开声音
    loop: false,      // 播完是否循环
    rate: 0.92,       // 播放速度，1 = 原速
    closePause: 1400  // 视频后那段话停留多久（毫秒）再翻到下一幕
  },

  typing: {
    speed: 15,        // ★ 正文打字速度：每秒打几个字（嫌快就调小，比如 10、8）
    titleSpeed: 11    // 标题速度，一般比正文再慢一点
  },

  fx: {
    particles: true,  // 背景漂浮的爱心 / 泡泡 / 猫爪印 / 星星
    sealSound: true,  // 开信封、打字、点小猫小鱼时的轻轻音效（右上角随时可关）
    heartCursor: true // 电脑上鼠标变爱心（手机无影响）
  }
};
```

文字里可以用 `<em>重点</em>`，会显示成粉色加粗。

### 小猫、小鱼和罐子

| 形象 | 出现在哪 | 会做什么 |
| --- | --- | --- |
| 🐱 小猫 | 信封左下角探头、信纸角落、落款 | 眨眼、甩尾巴、动耳朵；点一下撒爱心 |
| 🐟 小鱼 | 信封右上角、信纸角落、视频占位卡、落款 | 摆尾、摆鳍、吐泡泡；点一下冒泡泡 |
| 🫙 装爱心的罐子 | 信封右下角 | 轻轻晃动、星星闪；点一下撒爱心 |
| 🔴 火漆印章 | 信封正中（点它开信） | 默认是小鱼图案，可换成爱心 |

想改大小：`styles.css` 里搜 `.mascot-cat` / `.mascot-fish` / `.mascot-jar` 的 `width`、`height`。
想改颜色：最上面 `:root` 那一段，以及 `app.js` 里 `CAT_SVG` / `FISH_SVG` 的 `#f7ab5f`、`#ff8f3f` 这些色值。

### 打字速度怎么调

`typing.speed` 就是**每秒打几个字**：

| 数值 | 感觉 |
| --- | --- |
| 8 | 很慢，一个字一个字往外蹦，适合很短很戳心的话 |
| 12 | 偏慢，像一边想一边写 |
| **15** | **默认**，接近慢慢说话的节奏 |
| 24 | 偏快 |
| 40 | 飞快（几乎是一下子出现） |

另外，`。！？` 这种句末标点后面会自动多停一拍（约 0.37 秒），`，、` 后面停短一点，
所以不用自己加停顿；光标（小爱心）会一直停在正在打的那个字后面。
标题用 `typing.titleSpeed` 单独控制。

## 3. 放视频

把视频文件丢进 `assets/` 文件夹，比如 `assets/video1.mp4`，
再在 `config.js` 里把 `video: 'assets/video1.mp4'` 写上（路径要和文件名完全一致，注意大小写）。

想让某个视频走**全屏**：把 `video.mode` 改成 `'cine'`，视频会占满整个屏幕播放，右上角有「跳过」。

**视频规格建议**（微信里播放最稳）：

| 项目 | 建议 |
| --- | --- |
| 格式 | `.mp4`（H.264 视频 + AAC 音频），兼容性最好 |
| 分辨率 | 1080p 以内，竖屏 1080×1920 也行（会自动等比放进框里） |
| 大小 | 单个 50MB 以内；微信里太大加载慢，容易卡在转圈 |
| 命名 | 用英文/数字，别用中文和空格，省得路径出问题 |

> 还没放视频时不会出丑：信纸里会显示一张写着「视频还没放进来」的提示卡，旁边有「再看一次」按钮，
> 点「跳过视频」可以直接往下看。

## 4. 分享给 TA（微信里打开）

微信里不能像本地文件那样直接点开 `index.html`，需要放到网上。三种做法，从简单到讲究：

**① 最快的：GitHub Pages（免费）**
1. 注册 <https://github.com>，新建一个仓库（Public）。
2. 把 `index.html`、`styles.css`、`config.js`、`app.js`、`assets/` 全部上传上去。
3. 仓库 → Settings → Pages → Source 选 `main` + `/ (root)` → Save。
4. 等一两分钟，地址形如 `https://你的用户名.github.io/仓库名/`。
5. 把这个链接发给 TA，在微信里点开即可。

> 国内访问 GitHub Pages 有时会慢。在意速度就用下面的 ② 或 ③。

**② 腾讯云 COS / 阿里云 OSS 静态网站**
上传文件后开启「静态网站」功能，会给你一个 https 地址。国内访问快、稳定，适合放视频。

**③ Vercel / Cloudflare Pages**
把文件夹拖进去就自动部署，也免费，同样给一个 https 链接。

**微信里的小提醒**（都已经在代码里处理好了，知道就行）：
- 微信会拦住带声音的自动播放，所以视频默认**静音**开始，点视频右下角的小喇叭就能开声音；
- 页面右上角的音符按钮控制的是开信封、打字的音效，可以随时关掉；
- 有些安卓机（X5 内核）视频首次播放会先转圈，属正常；
- 换了新链接或新视频后，如果 TA 看到的是旧内容，让 TA 在微信里下拉刷新，或在链接后面加 `?v=2`。

## 5. 自检（可选）

改完 `config.js` 后想确认没写坏，可以跑一下自带的测试（需要电脑装了 Node.js）：

```powershell
node tests/smoke.js                  # 完整流程：开信 → 打字 → 视频 → 落款 → 收起 → 再看一遍
node tests/mascot-test.js            # 形象与特效：形象挂载、换幕轮换、点击反应、结尾彩带
node tests/gen-mode-test.js          # 生成模式测试（会自动读取你改过的 config.js）
node tests/mode-test.js natural      # 信纸内播放，视频自然播完后继续
node tests/mode-test.js cine         # 全屏播放模式
```

全部打印 `✅` 就说明没问题。这些脚本只是在假 DOM 上跑真实代码，纯粹用来查错，
不用它们也能正常使用，删掉 `tests/` 文件夹也不影响站点。

### 常见问题

**打开是黑的/只有背景？**
用 `file://` 直接打开不行，要起本地服务器或传到网上（见第 1、4 节）。

**视频不播？**
① 检查 `config.js` 里的路径和 `assets/` 里的文件名是否完全一致（含后缀）；
② 确认是 `.mp4`(H.264)；③ 视频太大就先压小一点。

**想改配色？**
打开 `styles.css` 最上面那一段 `:root{ --rose: … --env: … --paper: … }`，改几个颜色值整个页面就换风格了。

**想重看一遍？**
信纸右上角的 ✕ 收好这封信，再点一次信封即可；落款处轻触也可以。
